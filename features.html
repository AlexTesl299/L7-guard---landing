Technical Specifications

⚙️

Architecture & Routing

  • Go-powered Single Binary under 10MB: The entire backend is written in Go, weighs less than 10MB, and runs lightning-fast.
  • Browser Extension (Clientless): Access is granted through a lightweight browser extension. No bulky desktop VPNs.
  • Zero-copy & SNI-routing: High-speed routing without packet inspection or decryption (No MITM).
  • Per-Tab Split Tunneling: Route traffic to different gateways directly from adjacent browser tabs.
  • Dynamic Domain Rotation: Smart Chromium cache bypass using automatic Wildcard domain rotation.
  • Stealth Mode: The gateway returns a 404 error to random bots, pretending the page doesn't exist.
🔐

Access Control

  • JIT Access: Temporary access tokens for contractors.
  • Stateful TTL: Modify token lifespans on the fly.
  • Instant Kill-Switch: Revoke access in milliseconds without server restarts.
  • Bandwidth Quota: Strict limits on data downloads.
  • Dynamic ACL: Change access policies in real-time.
👻

WordPress Plugin

  • IP Whitelisting Core: Block login access for all IPs except L7 gateways.
  • Dynamic API Updates: Automatically update the list of allowed IPs.
  • Fail-safe: Easily disable protection with a single line in wp-config.php.
🕵️

Privacy & Identity

  • Zero Logs: We don't write logs or store PII. Absolute privacy.
  • SSO Integration: Google, GitHub, GitLab, MS Entra.
  • Passphrase Tokens: Add an extra layer of password protection to your tokens.

Built to handle heavy workloads. Independent nodes with no single point of failure (SPOF).
